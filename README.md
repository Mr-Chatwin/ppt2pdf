# 🚀 DeskKit (桌面百宝箱) - 极简离线工具集

**一款小巧、无需联网、永久免费的 Office 格式转换与 PDF 处理利器，未来将加入更多实用小工具！**

如果你正在发愁如何把大量的 Office 文件转为 PDF，或者需要将 PDF 快速导出为高画质图片，又不想使用网上那些充满广告、需要上传隐私的在线工具，那么 **DeskKit** 就是为你量身打造的。

## 🎯 我们的绝对优势

### 📂 1. 万能格式吞噬者
你可以把一堆 **Word (`.doc`, `.docx`)**、**Excel 表格 (`.xls`, `.xlsx`)** 以及 **PPT 幻灯片 (`.ppt`, `.pptx`)** 混杂在一起，闭着眼睛直接拖拽到主窗口中，系统会自动分拣并进入转换队列，无需人工整理！

### 🖼️ 2. PDF 高清无损转图片 (Windows 特供)
基于 Windows 系统内置的高性能 PDF 渲染引擎（原生 API）：
- 零外部依赖，极速转换，转换过程离线安全。
- 支持自由设定 **DPI (分辨率)**，不管是屏幕阅读还是高清打印都能轻松适配。
- 支持导出为 **PNG / JPG** 格式，PDF 的每一页都会被精准输出为独立图片。

### ⚡ 3. 恐怖的转换速度
底层基于后台进程驻留和全自动聚合批处理技术。不论是几十个表格还是上百个合同，只需启动一次常驻环境，便能瞬间行云流水般抽出完美的 PDF 产物！

### 🤫 4. 百分百隐私安全：永远断网运行
所有的操作都在您本地电脑上以绝对静默的方式运行，不会上传任何数据至任何服务器。连转换时的后台黑框都不会出现，确保您的机密合同与敏感报表万无一失。

### 🗜️ 5. 极致微型体积
不同于市面上动辄一两百兆的 Electron 套壳软件，我们基于 Rust + Tauri 底层原生框架，将体积硬生生压到了 **不足 10 MB**！不管是放在 U 盘里还是微信发给同事，都是瞬发的福音。

## 💻 快速开始

1. **下载使用**：前往本项目的 Release 页面，下载最新版的独立绿色版 `.exe`。
2. **免安装直通**：直接双击即用，拖入您的文件，点击“一键极速转换”或“PDF转图片”。
3. **查收成果**：转换出来的产物（PDF 或 图片文件夹）将自动保存在原始文件的同级目录下！

## 🛠️ 本地开发

如果您想参与二次开发或者本地调试：

```bash
# 确保安装了 Rust 和 Node (v20以上)
npm install
npm run tauri dev      # 启动带热更新的调试版界面
npm run tauri build    # 编译并打包体积仅几 MB 的最终版 EXE！
```
